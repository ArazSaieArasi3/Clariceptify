# Canonical ownership and selective migration

Decision date: 2026-10-24. Status: adopted for the R1 preparation scope. Evidence: issue [#3](https://github.com/ArazSaieArasi3/Clariceptify/issues/3).

Clariceptify is the destination for the selected conceptualization model and its future release lifecycle. The conceptualization-ontology repository remains the historical thesis/engineering source. Its releases and broader semantic work retain their original identities and are not superseded globally by this repository.

The existing research binding is R-001 (P1 / P1-L1); this repository is an artifact execution/publication surface of that research, not a newly minted Research identity. Portfolio still owns research identity and governance; OGCM-RF owns reusable engineering methods; this repository owns its local artifacts and evidence.

Canonical handover of the selected slice is pending registry import, parity checks, relevant validation and an explicit handover disposition. Destination preparation does not declare that handover complete. No source cleanup, upstream manifest update, mass branch migration or retagging is authorized by this local decision. No edits were made upstream in this wave.

Pin the selected source main to commit `80289f07866def38d077a9434803b6c85448d378`. The later candidate branch at `8ba73130e3162ecf2216dee34ecaa0c45a96e0a4` is a separate, unaccepted input and is not adopted merely because it is newer. The selected DOCX is an independently versioned input, not a file proved present at source main.

Transfer raw bytes only with an explicit distribution disposition. A same-label match between old and new catalogues is a candidate correspondence, never an automatic identity or owl:equivalentClass assertion. Preserve qualified historical IDs, even when meaning or representation has changed.

The name araz-research-ontology could not be resolved in the observed connection; araz-research-portfolio is the verified governance source. This is an explicit interpretation, not an assertion that the names denote the same repository.
