Creators in the owner-declared order are Araz Saie Arasi, Hassan Haghighi and
Hossein azgomi. Use the single root [CITATION.cff](../../CITATION.cff) for the
scientific package and cite the exact version you used. The actual publication
date is supplied by the GitHub Release record; no DOI has been issued.

[scoped LICENSE](../../LICENSE), with [third-party notices](../../THIRD-PARTY-NOTICES.md).
The project does not relicense cited publications, private raw inputs or dependencies.
Preserve attribution, provenance and version qualifications and identify modifications.

The documentation follows OntoSPK's publication architecture but is independently
implemented for Clariceptify's conceptual registers. It does not reuse OntoSPK
scientific results or imply a project-wide license decision for that other repository.
Detailed contribution-taxonomy roles remain unassessed; package creators are not
inferred independent reviewers.
