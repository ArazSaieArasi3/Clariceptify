# Clariceptify documentation

Clariceptify represents explicit, purposeful conceptualization: who conceptualizes,
which activity is performed, the content produced, its representations and the
reasons recorded for conceptual choices. The published conceptual baseline is
**v0.1.0**; these reader surfaces are documentation **v0.1.1** over that same core.

Start with [Overview](Overview.md), [Conceptual Model](Conceptual-Model.md) and
[Requirements and CQs](Requirements-and-CQs.md). Use the complete
[concept/domain reference](../reference/README.md),
[relationship tables](../reference/relations/README.md) and
[textual constraints](../reference/constraints/README.md) for exact lookup.

[Quality](Quality.md) distinguishes actual engineering evidence from unperformed
scientific assessments. [Visualization](Visualization.md) connects the SVG, vector
PDF and A3 atlas. Read [Limitations](Limitations.md) before using the model.

The [reproduction guide](Reproduce.md), [versions](Versions.md),
[citation](Citation.md), [sources](Sources.md) and [research roadmap](Research-Roadmap.md)
connect the artifact, evidence and next steps. The guide and detailed generated
views share controlled repository sources; Wiki and HTML are reader projections.
