# Research and release roadmap

The current stable scientific baseline is v0.1.0. The owner prioritizes
reader-facing documentation now, initial manuscript/artifact alignment next,
and more detailed source, domain and CQ evaluation through R2.

| Station | Intended result |
| --- | --- |
| v0.1.1 | Versioned Wiki/Pages, complete conceptual reference and search |
| v0.1.2 | Improved first manuscript and explicit artifact/evidence alignment |
| v0.2.0-alpha.1 | Closest-work paper/artifact comparison preview |
| v0.2.0-alpha.2 | Priority domain/source adequacy and initial CQ findings |
| v0.2.0-beta.1 | VVEAA evidence and manuscript/claim consolidation |
| v0.2.0-rc.1 | Exact reviewed R2 package and readback |
| v0.2.0 | Assessed conceptual baseline and declared corrections |

Stations are planned unless the actual release index says issued. The
[release sequence](../development/release-sequence.md),
[VVEAA profile](../../evaluation/vveaa-profile.yaml) and
[central issue roadmap](https://github.com/ArazSaieArasi3/Clariceptify/issues/1)
record evidence gates. Existing scientific reviews retain their AC/NAC and
prerequisites. Archive/DOI and full formalization are separate tracks.
