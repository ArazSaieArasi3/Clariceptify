# Versions and publication identity

Scientific baseline **v0.1.0** contains model **input-r1-rev1** and diagram
**diagram-r1.2**. Documentation **v0.1.1** presents that same scientific core.
Manuscript revision is a separate artifact identity; it is not an ontology release.

The [release index](../../releases/release-index.yaml) identifies actual issued
packages. GitHub Releases establishes issuance. The Pages publication manifest
identifies the deployed source commit. The current route is mutable; a frozen
release route is rebuilt from its registered immutable source ref.

Never move published tags or replace scholarly payloads. Editorial/documentation
patches preserve scientific commitments; semantic changes require an explicit
model delta and the appropriate next release. A future DOI is a separate issuance.

The [release sequence](../development/release-sequence.md) sets v0.1.1 documentation,
v0.1.2 manuscript alignment, R2 comparison and adequacy previews, an evaluation
consolidation beta, then the exact R2 candidate and stable v0.2.0.
