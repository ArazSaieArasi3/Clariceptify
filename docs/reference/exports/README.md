# CSV export contract

Generated view. Edit the authoritative registries, then regenerate. Model: `input-r1-rev1`; lifecycle: candidate.

UTF-8, RFC-style quoting, LF record separator. Every source field is retained. Strings stay strings; lists, dictionaries, booleans and null are JSON-serialized in cells. Decode by the authoritative record schema; CSV is not a second editing authority.
