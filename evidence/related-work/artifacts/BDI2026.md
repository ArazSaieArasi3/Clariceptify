### Q05: Time and interval obligations

A TimeInstant may have no date value; bdi:time has TimeInterval domain, allowing instant/interval co-typing because they are not declared disjoint. CQ9 uses atTime/interval start rather than a generation event;CQ17 filters dates procedurally and likewise uses atTime, not hasValidity;CQ18 lists explicit change links rather than computing a revised world/state.

### Q06: Plans, ordering and execution

A Plan may lack components or an execution; mandatory component and intention-specifies-Plan existentials from the paper are absent in the core. hasPart is reflexive: no-parts contradicts it, but a Plan whose only part is itself is consistent, so a proper subplan is not forced. Task precedence admits cycles and branches; transitivity does force shortcuts. beginsWith is asserted inverseOf endsWith, a questionable endpoint correspondence, rather than a tested requirement of a total task order. CQ15 orders rows by task IRI, not by a verified topological sequence. No actual action completion or goal success follows.

Locators: Plan/hasPart/hasComponent;Intention/specifies; precedes/follows;beginsWith/endsWith; unit-test-15; paper AppendixB44-70.

## Reproduce

Use the pinned [source manifest](../corpus/bdi2026-inputs.yaml), keep raw files outside the repository and install `requirements-bdi-review.txt`. The inspector verifies every input digest before parsing; it makes no implicit network imports.

```bash
python tools/inspect_bdi2026.py census --source-dir /external/inputs --output /external/census.json
python tools/inspect_bdi2026.py cqs --source-dir /external/inputs --output /external/cqs.json
python tools/inspect_bdi2026.py reason --source-dir /external/inputs --output /external/semantics.json --private-dir /external/reasoner-inputs
python tools/check_bdi2026_review.py --source-dir /external/inputs
```

The default public checker checks recorded evidence/provenance and rendered parity; it does not rerun HermiT, issue requests to remote sources or validate all meanings.
