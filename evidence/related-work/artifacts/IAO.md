# IAO release root: technical review (#240)

The [official repository](https://github.com/information-artifact-ontology/IAO) distinguishes its release `iao.owl` from development `iao-edit.owl` in the [pinned README](https://github.com/information-artifact-ontology/IAO/blob/3006aedacbf813ffd1d2ac15cda10766ca9ed388/README.md). The selected release is [the 2026-03-30 root](https://github.com/information-artifact-ontology/IAO/blob/3006aedacbf813ffd1d2ac15cda10766ca9ed388/iao.owl) at commit `3006aedacbf813ffd1d2ac15cda10766ca9ed388`, SHA-256 `c27ff2964a2ad8165bc365698b628aae95108411384aa4450e6e1b1e82bf0f41`. Its RDF/XML ontology IRI is `http://purl.obolibrary.org/obo/iao.owl`; its version IRI ends `/2026-03-30/iao.owl`. The root declares a CC-BY-4.0 license. The 2015 [paper review](../deep-reviews/IAO2015/report.md) addresses a conceptual proposal, not these release bytes.

The [complete root census](../../../evaluation/related-work/iao240/census.json) records all **266 named class declarations**: 210 IAO-IRI classes and 56 bundled external-IRI declarations (35 BFO, six APOLLO, five PATO, four OBI, three UO, two COB and one obsolete-class helper). It also records 31 anonymous `owl:Class` nodes separately. All 210 local classes have labels; 197 have an IAO source definition and 13 have no definition in this root. Sixteen local classes are marked deprecated. Of the 56 external declarations, 32 have source definitions, 24 do not, and one lacks a label. Each catalog row gives its IRI, label, exact source definition/comment or explicit missing state, source locator, asserted hierarchy/equivalence/disjointness expression and deprecation flag. The source text is attributed to the Information Artifact Ontology contributors under the root's CC-BY-4.0 license; retaining its original annotation avoids inventing paraphrases for 266 heterogeneous terms. The eight selected terms have short interpreted glosses in the [structured record](IAO.yaml).

The selected release has **no `owl:imports` statements**. The README lists BFO, OMO, RO core and three local files as development imports of `iao-edit.owl`, which are not direct imports of this release. The 35 BFO declarations and RO properties show structural reuse, but the selected root does not pin a specific BFO edition for the bundled axioms. The paper's proposed MFO extension is a separate author claim, not an established formal dependency of these release bytes. No historical OWL directories were summed and no inferred class count is claimed.

The [reproducer](../../../tools/inspect_iao240.py) verifies the exact SHA, parses 5,210 triples and checks eight asserted commitments: ICE under BFO generically dependent continuant, its `is_about some BFO:entity` restriction, the `is_about` domain, data entity and document under ICE, material information bearer under BFO material entity, inverse concretization relations and deprecation of `represents`. This is an asserted-graph inspection, not a profile or consistency test. `IAO_0000027` is labeled **data entity** in this root, although the pinned README calls it “data item”; the release label governs this census. The selected `represents` property is deprecated. Neither a same-name representation class nor the paper's referring-unit taxonomy is established as a selected release class by this inspection.

For a positive candidate, a document about an observed event can distinguish information content from a material bearer while using IAO aboutness. For an adverse case, a mistaken or fictional report can intend a target without successful reference. The existential restriction supplies some BFO entity under OWL semantics; it does not identify a verified real-world referent, the reporter, a decision episode, or the distinction between intended and successful aboutness. No ABox, OWL 2 DL profile, reasoner, or expert validation was executed here. Reuse of content/carrier/aboutness is a candidate input to #254 and final #126; equivalence and ontology changes remain unaccepted.
