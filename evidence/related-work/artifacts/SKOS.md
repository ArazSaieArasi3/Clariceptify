# SKOS selected RDF schema: bounded technical review (#238)

The selected [W3C RDF/XML schema](https://www.w3.org/2009/08/skos-reference/skos.rdf) matches the existing corpus SHA-256 `e79633b8d0564816cee8a99f5c9acf9a0e6fc7257c7209acd684ecad53a89dd6` (28,966 bytes). It accompanies the [18 August 2009 Recommendation](https://www.w3.org/TR/2009/REC-skos-reference-20090818/) and [namespace document](https://www.w3.org/2009/08/skos-reference/skos.html). This is a standalone public formal file, not a pinned repository commit. The checked W3C links establish authorship and edition but do not establish an independent public Git tree or exact correspondence with every historical serialization. No third-party bytes are redistributed.

The [reproducible census](../../../evaluation/related-work/skos238/census.json) and [inspection script](../../../tools/inspect_skos238.py) account for every named class in this selected root: `skos:Concept`, `skos:ConceptScheme`, `skos:Collection`, and `skos:OrderedCollection`. Each has an English `skos:definition`, an exact IRI and class axioms in the census; none has an `rdfs:comment`. There are no external named class redeclarations or declared `owl:imports`. The 252-triple graph separately declares 17 object properties, one datatype property and ten annotation properties. The 28 `rdf:Property` declarations overlap these types. Inferred class count is unknown because no entailment pass was run. Blank nodes are not additional named classes.

Eight selected RDF assertions were checked directly. They cover OrderedCollection subclassing, class disjointness, broader/transitive broader, related symmetry, exactMatch transitivity and memberList domain. The [Recommendation review](../reviews/SKOS.md) records further semantic and integrity statements, including preferred-label cardinality and disjoint label extensions. The schema's asserted triples alone do not implement all those application-level conditions. In particular, two preferred labels in the same language provide an adverse S14 case; this report does not claim to have executed an integrity validator on it.

For a common conceptualization scenario, SKOS can identify a vocabulary concept, place it in a scheme and give it a label or definition. A person, a time-bounded act of choosing the concept and the rationale or evidence for that choice require separate modeling. SKOS's unit-of-thought wording is contrary evidence to a claim that it has no conceptual-content perspective; it does not by itself identify the person's mental state. Treat labels, scheme membership and documentation as reuse candidates. No equivalence with a Clariceptify class has been accepted.

The selected vocabulary builds on RDF/RDFS/OWL constructs and declares no upper-ontology import. Neither UFO nor BFO grounding or an edition is established. OWL profile, HermiT, SHACL, import closure and expert validation were not executed. This review feeds comparison #253 and synthesis #126 without changing the ontology, requirements, manuscript or release. [Structured record](SKOS.yaml).
