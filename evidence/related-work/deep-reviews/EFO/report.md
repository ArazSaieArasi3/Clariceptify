### D2_problem_contribution

The author proposes a foundational epistemic ontology for knowledge as subject-held general thought objects, rather than a direct realist inventory of universals. Contributions are explicit metaphysical choices, a category map and a small FOL outline for singular thought objects. Its claimed role as reference ontology is an aspiration grounded in defended principles, not a demonstrated universal consensus. [AUTHOR_REPORTED; E01, E02, E06, E12, E15]

### D3_method

The method combines philosophical argument, interpretation of psychology/science, descriptive examples and illustrative formal axioms. The author explicitly chooses himself as the reference subject. Cited psychological experiments motivate commitments but are external studies, not a newly run EFO validation sample. Complete domain expansion and applications remain future work. [REVIEWER_INTERPRETATION; E04, E05, E06, E09, E12, E15]

### D4_requirements

Intended function is a reference ontology enabling knowledge sharing while preserving private concepts, dynamic conceptions, differing subject perspectives and fictional reference. No explicit executable CQ suite is supplied. Reconstructed cases include common-sense/scientific color, a cultural fictional character versus an in-world person, temperature-change judgment and multiple Paul aspects. [REVIEWER_INTERPRETATION; E03, E04, E09, E10, E11]

### D5_concepts

The main levels are concept vehicle, changing conception/content, thought object and transcendent target. General thought objects organize categories, but the FOL outline quantifies over singular thought objects only. Worldly entities are physical/mental, temporary entities endure, and events are treated as psychical continuants. This differs substantially from same-named DOLCE/BFO categories. [AUTHOR_REPORTED; E02, E03, E07, E08, E10, E12, E13]

### D6_relations_formalization

The core uses in, presentAt, position, possessedBy, object and represents plus an existence-as-such predicate. A2 enforces one world per worldly entity; A9 one human possessor per concept; A11 one inverse concept per entity. It does not state one object per concept. Printed presentAt/presentAt-with-accent and existsAsSuch/existsInItself spellings differ. A14-A15 can conflict for a source representing targets of opposite reference status. No solver execution is claimed. [REVIEWER_INTERPRETATION; E12, E13, E14]

### D7_grounding

Foundations are conceptualist/nominalist, subject-relative, presentist and endurantist, with realism of fictional worlds. Thought objects can have world-relative physical status while their conception is mental. The transcendent target lies outside the formal quantification domain, so reference existence is unary rather than a binary edge to an external object. Generic or collective subjects are not covered by the formal core. [AUTHOR_REPORTED; E02, E06, E07, E09, E13, E14]
