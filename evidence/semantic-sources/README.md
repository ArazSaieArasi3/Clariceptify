# Sources for bounded semantic reviews

These records preserve actually inspected scholarly/primary source versions and
precise section/page locators, with short paraphrases, metadata and reuse boundaries.
No third-party full texts or figures are redistributed. A source motivates a comparison;
it does not independently accept the current model or its OntoUML stereotypes.

[Review reports](../../evaluation/semantic-reviews/) bind each used record by SHA-256.
Source aliases are scoped to research batches; repeated authors/works are not independent
corroboration. Existing source-register metadata remains an unchanged imported baseline.
New records describe fresh inspection, not a retrospective rewrite of imported statuses.
