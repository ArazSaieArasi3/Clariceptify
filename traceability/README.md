# Traceability

[Artifact identities](artifacts.yaml) record 40 governed assets/collections with stable IDs, owners, storage revisions, digests and explicit unavailable states. The [artifact schema](schema/artifact-register.schema.json) governs those records. Model component IDs already present in the imported registries are preserved. File paths are locators; they are not entity identifiers. The collection fingerprint covers a sorted path-to-digest map, while the package version remains separate from the conceptual model's semantic status.

The register freezes input commit c5db7525fa3989fce292c6961e686dc4f25c9314 and separately hashes the actual alpha.2.1 publication receipt. A report's storage revision does not establish that its PASS applies to another input. Absent formal ontology, relational projection, reconciled diagram and generated specification remain explicit. The external draft manuscript is identified by SRC-ARTICLE in the migration input manifest; it is not a synchronized public manuscript. This initial register covers named primary families, not every historical file. Its own new control files are bound by their containing commit and later package manifests, avoiding recursive self-digests.

[Link types](link-types.yaml) and the [edge schema](schema/trace-edge.schema.json) define eleven initial project metadata links. Each edge requires typed endpoints, rationale, evidence locators and both endpoint revision/digest bindings. Structural membership, citation, inherited D/B/P support and candidate witnesses have distinct meanings. `proves` and `satisfies` are reserved and rejected by the initial schema. A bibliographic link, candidate witness or machine integrity result cannot be upgraded into proof, requirement satisfaction or independent acceptance.

Run `python tools/check_trace_contracts.py` for schema/snapshot checks and targeted negative cases. Rebuild the declared snapshot with `python tools/build_artifact_register.py`; changing a relevant authoritative file requires a new input ref and regenerated bindings. No complete generated trace graph or coverage result is claimed yet; #32 and subsequent work implement those outputs.

[Migration preparation](migration/) retains input identity and candidate correspondences. Candidate same-label links do not assert semantic equivalence, and source ownership is not silently transferred.
